The previous IQ test at counter 43288750 produced 44 TCX20 previous-core predictions and two two-bit SWB ACELP transition predictions. All 48 target bits were carried at opaque coordinates. Their values on that broadcast are unknown. This experiment measures the existing receiver rules under three different conditions.

## Authored radio service with a known sender

Use all 40 scored counters of the published clear `EF0201` radio fixture. Run the stock receiver once on the authored IQ. The frame order and service counter span are part of the fixture. Preserve each 60-slot group and every erasure. Build a forecast ledger from the accepted physical packets. The only word data required for these two rules are the current mode, the preceding mode within the group and, for the transition check, the final payload octet. Seal the forecasts before opening the separately saved pre-packetization G.192 words for scoring. The fixture and its whole-word results were examined previously. This is a retrospective control of the frozen rules and packet geometry.

Count TCX bit-8 predictions separately by transmitted value and frame position. For transition-tag words, report permitted pair values, singleton predictions, multi-value restrictions, unrestricted cases, and mismatches. Use constant predictions as baselines on the same comparable slots. Test neighboring-slot labels without crossing the 60-slot boundary. Check whether the predictor correctly uses a received predecessor mode even when another missing packet erases the rest of that predecessor word. Removing the prerequisite mode must cause abstention.

## Official floating-point EVS discontinuous-transmission controls

Use all three specified 3GPP TS 26.444 floating-point SWB cases named `stv32{c,n1,n2}_dtx_13200_32kHz` from archive `26444_g50-TestSeq_Float_26443.zip`. Include the ordinary .COD stream and its .f06.COD and .b10.COD variants in a separate cohort. Case names and ZIP directory metadata alone determine inclusion. Preserve original slot chronology, including bad frames, SID, no-data and other rates. Reset adjacency at file and 60-slot group boundaries. A bad or non-264-bit predecessor supplies no core evidence for the next slot. Use individually comparable, uncorrupted reference slots where the sibling streams have a verified shared alignment. Record any unavailable labels or incompatible files. The data test a publicly specified encoder under these configurations.
