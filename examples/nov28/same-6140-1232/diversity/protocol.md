# Development experiment on the 12:32 UTC same-carrier pair

Use only the previously released 12:32 UTC Edogawa and Yokohama 6140 kHz IQ. Record both observer binary/source hashes and both native output hashes. Match soft callbacks to native rows by their full hard-decoded record bytes and chronology, rejecting ambiguity. Each site's standalone re-decoder must reproduce all matched native rows byte for byte using the unchanged cell magnitudes and complex values. Process only blocks using the same 16-QAM standard mapping and identical MSC layout. The two-site alignment and calibration/guard/evaluation partition are defined separately by the independent wire witness map. In particular the two sites' stream record indices need not coincide. Do not interpolate across unanchored training/test rows or choose the offset that maximises combined CRC.

One fixed combining rule. At a matched block, a finite complex cell with finite positive rChan smaller than 1e30 is usable. The last value excludes Dream's 3.4e38 erasure tag. For each site form w[i] = 10^(SNRdB/10) * rChan[i]^2/mean(rChan^2 over usable cells), using Dream's SNR estimate at the callback, quantized to millidecibels in the observer. When all cells are unusable assign zero weight. Average the two complex values with their respective weights and pass sqrt(wE+wY) as the stock decoder's channel magnitude; when both weights are zero pass Dream's erasure tag with zero complex signal. This is an engineering approximation to inverse-noise-variance combining. Receiver SNR estimates describe a block and are not ground truth. Report every outcome even if a stronger individual branch or hard CRC union wins.

Keep the Edogawa target row fixed. As predeclared timing controls, move only Yokohama by −1 and +1 cell (cyclic within each block); separately use its actual immediately preceding or following native block. Skip block controls at boundaries, ambiguous hard-to-soft mapping or changed coding geometry. The same rule/weights are used in each case. Count exact-header + transmitted-CRC valid packets at each target row/ordinal, and complete DUs with all four packet CRCs and a valid transmitted DU CRC. Record newly accepted observations vs the two-station hard-packet union, baseline losses, disagreements vs any available expected good receipt, and new DUs independently supported by that union. Checksums validate transmission integrity, not dates, absolute counter assignment or programme bits. No application fields are inputs to the combiner. The 13:47 recordings are excluded from this protocol.
