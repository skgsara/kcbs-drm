# Target bits and reference sources

The [IQ acquisition and primary-selection protocol](protocol.json) fixes one 90-second public reception in Edogawa. The 14,737 previously assigned counter IDs are in [the historical inventory](history.json.gz). The IQ and receiver are sealed before opening the samples for demodulation.

For a physically consecutive, intact pair of groups, use the final frame of the left group and the first frame of the right group. The two checks below use the chronological order and the public rules at revision `b1f1a6312e95ff67c1d296a0e9623819a9ae4758`. Each group contains 60 slots and word bit zero is the MSB of the mode octet.

* For the right frame, set its mode bit 6 aside before identifying an HQ frame. Under continuous 13.2 kb/s stock encoding, a preceding ACELP core predicts one at bit 6, and a preceding MDCT core predicts zero. A recognized prediction excludes the other value. Unknown predecessor indices or an ineligible right mode give no prediction. [Existing core history model](../../../scripts/evs_core_history.py)
* For the left frame, keep its payload octet 5 out of the predictor. Use the two mode octets and the right frame's directly carried payload octet 5 with the existing ACELP speech-class function. The returned class exclusions apply to the left frame's two-bit field only when both modes identify the field. Report the actual excluded values and restore the left octet only to score the prediction. [Existing class predictor](../../nov27/validation/acelp-class-history/check.py)

Apply the primary checks to frames belonging to the selected group. The first complete group can have a complete successor. Requiring an earlier, physically contiguous complete predecessor would itself have selected that predecessor first, so record an abstention at the primary left boundary. Report counts across the other fully received contiguous group pairs separately. A missing primary, discontinuity or empty eligible set remains visible. Each transmitted bit used for scoring comes from the one fixed RF capture. Those comparisons and any codec expectations for concealed bits have separate denominators. An unresolved clear word remains an erasure.

Separately, the November 28 member recording on 3205 kHz and the already decoded Edogawa recording on 6140 kHz are a retrospective two-receiver control. Score the right-frame HQ bit predicted from 3205 against the same coordinate received on 6140. Keep a missing peer reference as an erasure. Flipping the peer bit and using the previous group's predecessor in place of the true predecessor are controls for scoring and frame order. Both captures and their overlap have previously been examined. [Prior reception](../member-3205-20min/README.md)
