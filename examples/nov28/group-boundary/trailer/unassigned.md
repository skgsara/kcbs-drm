# Locating previously unassigned native packets

Freeze this historical recording test before inspecting the unassigned rows. The earlier alignment test queried packets that already had an assigned coordinate. Here the unit of selection is an original receiver row whose last packet passed its header and CRC checks and for which the stock packet salvage produced no coordinate for that row. The paired inputs are the member's original 3205 kHz MLC1 window 0 and the Edogawa 6140 kHz native MSC dump. Use the two later member windows only to establish the full member baseline, including existing receipts that cross a window boundary. Verify all four source hashes against the previously published [capture receipt](../../member-3205-20min/cross-frequency.json).

1. Run unmodified packet salvage separately at each station with transport-only output and packet receipts. Keep the original packet bodies, presence flags, receiver row numbers and the stock assignment provenance. Reject a row with any CRC-good wrong packet header or a complete row failing the DU CRC. Do not treat absence from the published 119-counter subset as an unassigned row.
2. Index the other station's **previously assigned** phase 1 and 2 fragments, including q3 from partial DUs. For each unassigned CRC-valid q3 in the two selected dumps, give the lookup both possible 33-byte windows at DU offsets [665,698) and [664,697). It receives no source phase, counter, row order or timing. Require exactly one distinct destination (counter, phase). Report zero or multiple matches separately.
3. Independently index accepted assigned packet bodies at the other station across all three phases, keyed by ordinal and all 179 body bytes. Require at least one other CRC-valid packet in the same native row, q0, q1 or q2, that uniquely identifies the same coordinate using this second index. Any uniquely identifying witness naming a different coordinate rejects the row. Check any available q0 phase, the entire q3 body, and all other packet bodies against every existing source or peer receipt at that coordinate. Reject contradictory observations. The two witnesses use disjoint physical packets from the same transmission.
4. Propose only the CRC-good bodies actually received in independently supported rows. Consolidate identical copies, quarantine any candidate tick with conflicting packets, and check the transmitted DU CRC wherever additions complete all four packets. Compare both station baselines and their union before and after addition, including packets, last-packet coordinates, complete DUs, complete three-DU groups and EVS slots with all wire octets available. Report established receiver coordinates separately from any coverage gained by their union. Derive every proposal from the original lookup indexes. No chaining or interpolation.
5. Report both directions, including absences, ambiguity, candidates with no independent witness and supported rows that duplicate existing data. This is a retrospective comparison of recordings of the same service with overlapping transmissions. A location requires the reference recording or another independent source of coordinates.

All coordinate indices in the receipt are zero-based except EVS position (1–4). The direction 3205→6140 denotes locating an unassigned 3205 row using the labelled 6140 archive, and conversely for 6140→3205.
