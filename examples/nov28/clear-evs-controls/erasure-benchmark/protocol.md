# Local blind test on erased bytes of standard EVS words

Freeze the following baselines and input selections before reading the new coded words or running the alternate radio reception. The codec experiment uses ordinary, unencrypted test sequences. It measures the ability to fill an erasure when the original is known to the scoring process. The separate radio experiment measures CRC-checked transport recovery from IQ.

## Codec inputs and permitted observations

Use all nine ordinary 13.2 kbit/s NB, WB and SWB streams (c, n1 and n2) from the official TS 26.444 `26444_g50-TestSeq_Float_26443.zip`. The matching nine earlier fixed-point streams serve as a previously examined comparison. ZIP-directory metadata indicates the two implementations encoded the same input recordings. Score the cohorts separately. If the official Annex A `Exps2a_x/preprocess/an1concat.32k` can be confirmed as signed 16-bit mono 32 kHz PCM, include it as a separate source using the stock TS 26.442 fixed-point encoder, `-q -no_delay_cmp -max_band SWB 13200 32`, DTX off. Keep source coordinates, SHA-256 digests and actual frame counts. [Previously examined fixed-point streams](../reference-members.json) · [Official sequences](https://www.3gpp.org/ftp/Specs/archive/26_series/26.444/test_sequences/)

Form consecutive, non-overlapping groups of 60 slots starting at slot zero of each file. Omit the final incomplete group and count its slots. Report and exclude a group containing a missing or bad word as a whole. Each group contains 15 repeats of P1, P2, P3, P4, in that order. Preserve the mode octet. Supply the full P1 word, erase six P2 payload offsets (15, 18, 21, 24, 27, 30), and erase every third payload byte from 0 through 30 at P3 and P4. Offsets start after the mode octet. Supplying clear P1 assumes those comparison words are available. The codec observations here contain erasures and omit the broadcast transport and its relationships across frames.

## Sealing and scoring

The preparer separates the public observations from the six clear reference bytes for each P2 word. The predictor reads only the observation file. Seal its choices by SHA-256 before providing the scorer with the answer file. Use three fixed receivers:

* The six public field checks retain an erasure wherever they leave all six missing bytes free. Treat all target values as tied when the visible word passes these checks. Report any contradictions in the visible fields separately. The existing checks read payload bytes 0, 4, 26 and 31 and the mode octet. [Published audit](../substitutions.json)
* The previous-frame copy baseline fills each erased byte with the same byte from the P1 immediately preceding it in this cycle. It makes one guess per field. It uses no learned parameters or audio reference.
* A second copy baseline makes the identical guess only if the full mode octets of the two words match. It otherwise abstains on all six bytes.

Report full six-byte exact words, incorrect complete guesses and abstentions or ties for each baseline. Count correct bytes and bits among actual guesses. At group level, count all 15 words exactly correct, all called with at least one error, and groups with an abstention. No confidence estimates are assigned to copy guesses. For the known p24 ambiguity control, use the previously published two complete stock streams, their group [180,240), and the same projection. Compare the observable and hidden digests. [Stock sender control](../../../nov27/validation/swb-gsc/README.md)
