# Prospective test of fourth-position payload octet 30

The project has proposed that position four carries payload octet 30 directly. We will test the statistical behaviour of the received octet on new IQ. Even a successful forecast of the received value leaves the clear value independently unverified.

Train on all 899 complete groups found in the three public March 16 IQ WAVs and the November 27 22:58 UTC 6140 kHz IQ recording. Reassemble with the Wiener profile and one MLC iteration. For the longest March file use 0–600 s and 590 s–EOF, pooling overlapping packet coordinates. The pooled data-unit archive has SHA-256 `3ba9b75cbb97e76dd0f4d5e5b194e5447fdb029d7a26ddb92eae54593758f567`. The training values are the received P4 octets at offset 30. The tables require only these four publicly available IQ recordings.

For the primary model, group training slots by their exact mode and directly transmitted payload offsets 28, 29 and 31. Within each group choose the most common received P4 octet 30, breaking ties toward the smaller value. Abstain on an unseen signature. A secondary model uses just the mode and offset 31. The mode-only baseline uses the same training words. The primary table has 12,238 signatures and SHA-256 `d82f84274bb1d232d504d17f7bf15a09035d0d311c3e5bac381694eaa6549160`. The secondary table has 1,564 signatures and SHA-256 `33a733c550b7d0d837e2bc271a8a6bb045ac3d93eeec6146069990c14883ff07`. The predictor and scorer are frozen together at SHA-256 `73a5bd56bf466f6eda9c53c04d01a8defffabbedf59ca530cb1e52b5fe5cb862`.

Acquire one 240-second recording on 6140 kHz at 7L4IOU in Edogawa. Use the original IQ, with Dream at one and four iterations, and pool packets passing CRC. Take the first complete counter in transmission order whatever its modes or number of predictions. Score it separately, followed by every complete counter. An empty reception or no matching P4 signatures is a retained result. The RF protocol has SHA-256 `955b63ea4c545968914c0425cd51aae93b5bc4673492e445d80a7a63d4de71c4`.

For both models, save the predictions and record their SHA-256 before opening received target values for scoring. Count abstentions and exact agreement with held-back received octets, separately by position. Score a control on the same matched slots by rotating target octets half a stratum, preserving mode and position. Exclude singletons from both sides of the rotated comparison. Score the mode-only baseline on matched slots. These empirical guesses exclude zero clear values. Retain full-word erasures and report codec counterexamples where available.
