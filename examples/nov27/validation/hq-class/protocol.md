# SWB HQ class test on recording and contributed archives

Freeze the standard 13.2 kb/s SWB low-rate HQ encoder class codes 00, 01 and 10. Predict using the directly received mode octet alone. For mode F9, physical bit 8 must be zero for this encoder. For FA and FB, bits 8 and 9 may be 00, 01 or 10. Bit 0 is the most significant bit of the mode octet. Keep every prediction conditional on the sender using this field layout. The receiver's output words retain their missing-byte markers.

Select the first complete CRC-checked counter in the window and report all complete counters for coverage.
